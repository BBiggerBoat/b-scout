# B-Atlas Production Validation Batch 03 — Mainship + Monk + Island Gypsy

**Release:** v6.33.0  
**Canonical architecture:** v1.4  
**Scope:** all 16 current B-Atlas records from Mainship, Monk and Island Gypsy.

## Mainship

This manufacturer validates the new Production Phase architecture particularly well.

- **30 Pilot:** one canonical model with an original phase (1998–2002) and Series II phase (2003–08). Series II changed the keel, propeller tunnel, propeller, engine choices and cabin arrangement. Draft therefore belongs at phase level rather than as one universal model value.
- **34 Diesel Cruiser / 34 I, 34 II and 34 III:** these have distinct manufacturer/market designations and remain separate canonical model/variant records. They are not collapsed merely because they share dimensions and lineage.
- **350 / 390 Trawler:** published history explicitly states that the 350 was called the 390 from 1999–2005. B-Atlas retains both searchable records for marketplace recognition while marking them as one continuing hull/model line.
- **400 Trawler:** 41 Expedition (2009) and 414 Trawler (2010–12) are aliases/renames of the same continuing model. The 2009 interior redesign is captured as a production phase.
- **34 Trawler (2005–09):** core specifications and separate stall shower canonicalized. Engine count remains unresolved because both single and twin installations were offered.

## Monk

The **Monk 36** remains one canonical model.

Two production phases now capture the material production change:
- 1982–91 Taiwan-built;
- 1992–2007 Nova Scotia-built.

The Canadian phase reduced exterior teak, removed the aft-head tub, revised master-berth placement and used later engine packages. None of this created a new model designation.

## Island Gypsy

- **32 Sedan / Europa / Fisherman:** the Fisherman explicitly uses the same basic hull mold as the Sedan but remains a distinct named model because mission, layout, weight and power differ. The Europa is also a distinct named layout/model.
- **36 Classic:** canonical dimensions corrected; published material explicitly associates it with the 36 Quad Cabin name. Engine count remains variable.
- **36 Europa:** legacy 12-foot beam / 16,000-pound values were incorrect; validated values are 13'6" beam and 25,520 lb.
- **40 Classic:** current B-Atlas range starts with the documented 1995 redesign, so a pre-1995 phase is not created inside this record.
- **44 Motor Cruiser:** legacy aft-cabin classification was incorrect. Published layout places the master amidships; the model remains a three-stateroom motor cruiser, not a conventional aft-cabin boat.

## Architecture lesson

This batch confirms three distinct mechanisms are necessary:

1. **Separate canonical models/variants** when the manufacturer/market gave boats distinct identities.
2. **Production phases** when a continuously named model changes materially.
3. **Aliases / continuity links** when the same model is renamed for marketing.

That prevents both over-splitting and over-merging.
