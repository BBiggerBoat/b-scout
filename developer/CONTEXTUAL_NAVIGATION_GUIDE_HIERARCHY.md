# B-Atlas Contextual Navigation Hierarchy

Updated: 2026-08-07

## Global navigation
- Plan
- Dream
- Saved Models
- My Boats
- About

Global navigation contains only destinations that make sense without a selected model.

## Start flow
Plan -> guided discovery/education.
Dream -> standard model search.

## Selected model
Opening a model enters its Guide.

Guide sections:
- Research
- Buy
- Owner Resources
- My Notes

Research, Buy and Owner Resources are intentionally contextual. They are not global header destinations.

## Individual owned boat
My Boats contains:
- Identification/purchase
- Engine
- Documents
- Maintenance
- Upgrades
- Contributions
- Prepare to Sell

Sell is intentionally attached to an individual owned boat rather than a generic model.

## Terminology
User-facing "Workspace" and "Boat Guide" should be avoided where "Guide", "Saved Models", "Listing Details", or "My Boats" is clearer.
Internal JavaScript identifiers may retain legacy workspace names for compatibility.
