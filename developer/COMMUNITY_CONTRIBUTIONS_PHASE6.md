# B-Atlas Community Contributions — Phase 6

## Purpose

Phase 6 allows the community to expand B-Atlas coverage by proposing missing manufacturers and missing models without directly creating canonical records.

## Add a manufacturer

Required:
- Manufacturer name

Optional:
- Country
- Established / first known year
- Last active year
- Website/source
- General notes
- Display attribution
- Private contact email

An exact manufacturer already represented in the canonical model catalog is blocked and redirected toward adding a missing model or correcting existing information.

## Add a missing model

Required:
- Manufacturer
- Model name

Optional:
- Variant/layout
- Boat family
- Production years
- Length
- Beam
- Fuel
- Propulsion
- Hull type/behaviour
- Source URL
- Model photo with rights declaration
- General notes
- Display attribution
- Private contact email

Existing manufacturers may be selected/typed without creating a second manufacturer record. Exact canonical model matches are blocked and redirected toward the existing Guide or correction workflow.

## Unknown-data behaviour

Contributors are not required to research a complete model record. Missing optional fields remain unknown and do not invalidate the proposal.

## Moderation boundary

All Phase 6 submissions use `ModerationStatus = pending` and enter the same prototype pending queue as earlier contribution types. They never create, modify or overwrite canonical manufacturer/model data automatically.

Shared contribution storage and the moderator review screen remain Phase 7.
