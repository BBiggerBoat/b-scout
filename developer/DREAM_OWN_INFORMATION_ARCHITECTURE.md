# Dream / Own Information Architecture

Updated: 2026-08-07

## Dreaming
Purpose: understand the permanent boat model and decide whether it deserves deeper research.

Contains:
- Overview and fit context
- Specifications and model variations
- Model character and design lineage
- Strengths, trade-offs and known model problems
- Ownership ease / maintenance ease as buyer-facing model characteristics
- Evidence and confidence

## Owning
Purpose: provide durable external resources useful to an owner.

Contains only:
- Manuals & Documents
- Groups & Clubs
- Videos & Virtual Tours

Explicitly excluded from Owning:
- Duplicate model specifications
- Duplicate strengths / trade-offs / problems
- Knowledge coverage dashboards
- Generic owner-action guidance
- Model images (already available elsewhere in the Boat Guide)

Unknown or missing owner resources remain unknown and do not imply a negative judgment.
