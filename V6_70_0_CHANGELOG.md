# B-Atlas v6.70.0 — Model Filters, Boat Watch, Support Preparation

## Boat Models
- Text Search moved back to the top of the Refine Model Matches column.
- All collapsible filter/profile/preference groups now start collapsed.
- Routes moved to the bottom of the filter sequence.
- Filtering and ranking logic unchanged.

## Saved Models — Boat Watch
- Added a dedicated Watch checkbox to Saved Models, separate from Compare selection.
- Added Create Boat Watch action with selected-model count.
- Boat Watch generates model-aware recurring monitoring instructions including each model's permanent B-Atlas URL.
- User can set geography, optional maximum price and additional requirements.
- "Copy & Open ChatGPT" copies the instructions and opens ChatGPT; the user pastes and confirms the recurring task.
- "Copy for another AI" provides a platform-neutral fallback.
- Prompt preserves the B-Atlas principle that missing information does not eliminate a candidate and asks the AI to deduplicate previously reported listings.

## Voluntary support review
- Ko-fi Free selected as the simplest no-fixed-cost option for one-time voluntary support.
- Ko-fi currently charges 0% platform fee on one-time tips when Standard is turned off; PayPal/Stripe processing fees still apply.
- Public support button is intentionally not activated in this build because a Ko-fi account/payment destination must be created and controlled by the B-Atlas owner first. See SUPPORT_B_ATLAS_SETUP.md.
