# B-Atlas v6.25.0 — Rebrand & UI Consolidation

## Brand
- Renamed the public product from **B-Scout** to **B-Atlas**.
- Tagline retained: **Boat Knowledge for Better Decisions**.
- Replaced the image-heavy B-Scout header identity with a cleaner text-based B-Atlas lockup across the app and generated research pages.
- Updated public-facing titles, descriptions, labels, guide language, moderator copy and generated-page brand references.

## UI / UX
- Preserved and consolidated the v6.24.1 VesselBook-inspired simplification pass.
- Reduced decorative header treatments on generated research pages.
- Flattened cards and controls further; hierarchy relies on whitespace, typography and restrained borders.
- Preserved the revised Plan hierarchy for LENGTH / BEAM, feature-question typography, text-first fuel choices and compact controls.
- Preserved Demo Fleet retirement/reset logic.

## Build integrity
- Resolved three unresolved Git merge-conflict blocks found in the supplied live-project ZIP (`package.json`, `styles.css`, `bscout-visual-standard.css`) by retaining the v6.24.1 side.
- Repository name and lowercase `/b-scout` technical URL references are intentionally unchanged in this release.
- Canonical URLs, sitemap domain migration, Schema.org URLs, IndexNow targets and search-engine migration are intentionally deferred to the dedicated SEO migration step.
