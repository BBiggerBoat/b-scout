# B-Atlas Production Validation Batch 04 — DeFever + Nordic Tugs + Kadey-Krogen + Willard

**Release:** v6.34.0  
**Canonical architecture:** v1.4

## DeFever

Eight current DeFever records were reviewed.

The major finding is the **38 Wood Passagemaker**. A documented 1972 Arthur DeFever 38 Passagemaker exists, built of mahogany in Japan, which directly contradicts B-Atlas's previous 1979 production start. Rather than invent a new range from one hull, the canonical start year is now unresolved and the documented 1972 hull is retained as evidence.

The 34 Passagemaker, 40 Offshore Cruiser, 41 Trawler, 43 Trawler, 45 Pilothouse, 47 POC and 49 Cockpit Motor Yacht received stronger model-level dimensions and hull classifications from dedicated model references.

## Nordic Tugs

The Nordic Tug family demonstrates both production phases and genuine name succession.

### Nordic Tug 26
Three production phases are now represented:
- original 1980–94 production;
- 1995–97 `2-26` update;
- 2009–18 reintroduced production.

### Nordic Tug 32
The 32 remains one canonical model, with:
- original phase;
- 2002 `32+` update;
- 2008 prop-pocket hull phase.

### Nordic Tug 37 / 39
The 39 replaced the 37 in 2010 while retaining the same Lynn Senour-designed hull. B-Atlas therefore preserves distinct searchable model names but records the shared-hull lineage.

## Kadey-Krogen

This batch produced one important identity correction.

### Krogen 44 vs 44 AE
The existing B-Atlas record mixed two manufacturer-recognized identities.

It is now split into:
- `KDKR-44` — Krogen 44 Trawler / Classic, 2004–2012
- `KDKR-44-AE` — Krogen 44 AE / Advanced Ergonomics, introduced 2012

This is a case where a new canonical identity is preferable to a production phase because the builder explicitly introduced the AE as a new named model with more than 50 ergonomic/technical changes.

### Krogen 42
The 42 remains one canonical model but now has construction phases:
- early glass-over-plywood deck/superstructure construction;
- fiberglass superstructure from 1985;
- solid-fiberglass hull from 1995.

### Krogen 48 North Sea
The legacy 1995–2007 range was corrected to the stronger documented 1996–2010 range.

## Willard

Willard's own historical material resolves a naming trap:

`Vega` described the hull style and **did not itself identify the model**.

The Vega 30 family used actual names such as Voyager, Searcher, Nomad and Horizon. Similarly, the Vega 40 included Nomad, Voyager and Motorsailer variants.

The post-1977 `Willard 40` was an updated model with molded fiberglass superstructure and walkaround side decks and should not be merged with the earlier Vega 40 Nomad.

## Architecture result

This batch reinforces the distinction between:
- continuous production phase,
- shared-hull successor,
- manufacturer rename,
- and genuinely new named canonical model.

The Kadey-Krogen 44/44 AE split is the strongest example in this batch.
