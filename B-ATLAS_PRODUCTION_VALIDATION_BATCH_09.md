# B-Atlas Production Validation Batch 09 — Bayliner + Carver + Silverton + Meridian

**Release:** v6.39.0  
**Canonical architecture:** v1.4

## Bayliner

This batch exposes extensive model-name evolution.

The 3270 Explorer became the 3270 Motor Yacht and then the 3288 Motor Yacht while retaining the same basic mid-cabin hull/layout lineage. B-Atlas records this as production naming phases rather than artificial unrelated models.

The 3788 Motor Yacht is more significant. The 1996–99 boat and the 2001–02 boat have materially different dimensions and interiors. They keep one model identity because Bayliner explicitly presented the later boat as an updated 3788, but dimensional facts are now phase-scoped.

The revised 2001–02 3788 then became the Meridian 381 in 2003.

Several smaller Ciera/Command Bridge records remain conservative where strong dedicated model references were not available in this pass.

## Carver

Carver used frequent numerical renaming:
- 3297 Mariner → 330 Mariner;
- 33 Aft Cabin → 350 Aft Cabin;
- 355 → 356 Motor Yacht;
- 350 Mariner → 36 Mariner;
- 3807 Aft Cabin → 390 Aft Cabin.

These are modeled as aliases/continuities unless the underlying boat materially changed.

The 350/36 Mariner gets separate naming/layout phases around the 2004 update.

One source-quality problem was caught: the HMY 355/356 page lists a 30-foot length, inconsistent with the model identity and lineage. B-Atlas keeps the conflict but does not canonically adopt the bad number.

## Silverton

Silverton's 372/392 Motor Yacht is one continuing SideWalk model: 372 from 1996–98 and 392 from 1999–2001.

The 34, 352, 372/392 and 40 Aft Cabin receive stronger dimensional and separate-stall-shower facts.

## Meridian

This batch required a true canonical split.

The legacy B-Atlas `Meridian 341 Sedan 2003–2014` was incorrect.

HMY explicitly states:
- 2003–04 341: essentially the former Bayliner 3488 Command Bridge;
- 2005–14 341: a completely different boat, wider and redesigned.

B-Atlas now contains two canonical records:
- `MERI-341-SE-03` — 2003–04 original generation;
- `MERI-341-SE` — 2005–14 second generation.

The Meridian 381 remains directly linked to the revised Bayliner 3788 lineage.

## Architecture result

This batch confirms that a numerical model name alone cannot define canonical identity. Builder intent, hull continuity, generation changes and marketing renames all have to be represented separately.
