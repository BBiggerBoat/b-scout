# B-Atlas v6.26.0 — Design System v1

## Purpose
Replace incremental styling patches with a single visual system intended to make B-Atlas read as a calm marine reference and research site rather than a dashboard-style web application.

## Changes
- Added `batlas-design-system.css`, loaded last so the design system normalizes legacy page-specific CSS.
- Rebuilt the text-first B-Atlas header lockup with clear separation between name and tagline.
- Removed the orange header rule, heavy navigation separators, forced uppercase navigation and excess nav weight.
- Standardized typography around four useful levels: page title, section title, body and supporting/meta text.
- Reduced main reading width and improved line length.
- Simplified Plan choices from boxed cards to flat two-column choices separated by light rules; selected choices use a restrained highlight and left accent.
- Simplified progress treatment and Plan panels.
- Flattened Home entry cards and reduced decorative framing.
- Harmonized Dream, Contribute and modal styling with the same colours, borders, type and radii.
- Added mobile rules for the revised header and Plan layout.

## Deliberately unchanged
- Repository name (`BBiggerBoat/b-scout`).
- Canonical URLs, sitemap, Schema.org URLs and other SEO migration work.
- Final graphic logo. This release establishes the interface language first; a future logo can be designed to fit it.
